# Solitude Dusk for VS Code

Warm charcoal and a single setting-sun gold `#db9617`. The VS Code half of the
[Solitude Dusk](https://github.com/iam-wisman/solitude-dusk) Omarchy theme:
editor `#171717`, side bars and panels a shade darker at `#121212`, gold
cursor, gold top edge on the active tab, and soft evening syntax colours
(twilight blue functions, gold types, mist properties, olive strings).

Installed and applied to every VS Code profile by the theme's `install.sh`.
